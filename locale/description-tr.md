# Gm Resource Modifier

**Yazar**: [TheRedDaemon](https://github.com/TheRedDaemon/ucp_gmResourceModifier)

Bu modül, oyunun yüklenmiş GM1 kaynaklarını değiştirmeyi sağlar. Crusader, GM dosyalarını TGX dosyalarından farklı işler: TGX gerektiğinde diskten okunur, GM ise başlangıçta yüklenir. Bu nedenle yalnızca dosya erişimini yakalayıp yolları değiştirmek yeterli değildir. Gerektiğinde değiştirebilmek için bellekteki GM dosyalarının kontrol yapıları belirlenmiştir.

Bir dosyanın tamamı veya tek tek resimler değiştirilebilir. SHC, GM1 içinde farklı biçimler sakladığından türlerin aynı olması gerekir. Modül ayrıca bir resimden tek resimli “interface” türü kaynak oluşturabilir. Dönüştürücü Windows işlevlerini çağırır; destek işletim sistemine ve Wine’ın sunduklarına bağlıdır.

Modül doğrudan oyun özelliği sunmaz; alt düzey bir temel sağlar. Daha fazla bilgi için deponun README dosyasına bakın.
