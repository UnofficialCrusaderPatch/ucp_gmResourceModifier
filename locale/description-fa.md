# Gm Resource Modifier

**نویسنده**: [TheRedDaemon](https://github.com/TheRedDaemon/ucp_gmResourceModifier)

این ماژول امکان تغییر منابع GM1 بارگذاری‌شدهٔ بازی را فراهم می‌کند. Crusader فایل‌های GM را متفاوت از TGX پردازش می‌کند: TGX هنگام نیاز از دیسک خوانده می‌شود، اما GM در شروع بازی بارگذاری می‌شود. بنابراین گرفتن دسترسی فایل و تغییر مسیر کافی نیست. ساختارهای کنترل GMهای موجود در حافظه شناسایی شده‌اند تا بتوان آن‌ها را هنگام نیاز جایگزین کرد.

می‌توان کل فایل یا تصویرهای جداگانه را جایگزین کرد، اما نوع باید یکسان باشد؛ چون SHC قالب‌های متفاوتی در GM1 ذخیره می‌کند. همچنین ماژول می‌تواند از یک تصویر، منبع تک‌تصویری از نوع «interface» بسازد. تبدیل‌کننده توابع Windows را فراخوانی می‌کند، پس پشتیبانی به سیستم‌عامل و قابلیت‌های Wine وابسته است.

ماژول به‌تنهایی قابلیت مستقیمی برای بازی ندارد و زیرساختی سطح پایین است. برای جزئیات، README مخزن را بخوانید.
