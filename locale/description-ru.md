# Gm Resource Modifier

**Автор**: [TheRedDaemon](https://github.com/TheRedDaemon/ucp_gmResourceModifier)

Модуль позволяет изменять уже загруженные ресурсы GM1 игры. Crusader обрабатывает GM иначе, чем TGX: TGX читаются с диска по запросу, а GM загружаются при запуске. Поэтому одного перехвата доступа и замены путей недостаточно. Для замены по запросу были определены структуры управления GM-файлами в памяти.

Можно заменять целые файлы или отдельные изображения. Тип должен совпадать, поскольку SHC хранит разные форматы в GM1. Также модуль умеет создавать из изображения одиночный графический ресурс типа «interface». Конвертер использует функции Windows, поэтому поддержка зависит от ОС и возможностей Wine.

Модуль не предоставляет самостоятельных игровых функций и служит низкоуровневой основой. Подробнее см. README репозитория.
